Key Decisions

Drag-and-drop

Use @dnd-kit/core — lightweight, accessible, built for React. Handles reorder in the pipeline list, then PUTs the new order to the backend.

HLS playback

Use hls.js — the standard for HLS in browsers. Points at the existing /stream/playlist.m3u8 endpoint. Low-latency config to minimize the delay.

Dev workflow

vite dev with proxy to localhost:3000 (Rust). Hot reload on React changes, cargo run for backend. Two terminals.

Production build

vite build → static files embedded in Rust binary via include_dir crate. Single binary serves both API and frontend.
