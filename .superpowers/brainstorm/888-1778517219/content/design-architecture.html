System Architecture

livestream-morphing-rs/ (Axum)
📡 Stream Source (Abbey Road)
🎨 Effect Registry (macro-registered)
⚙️ Pipeline Engine (ordered effects)
📺 HLS Server (segments + playlist)
💾 Preset Storage (TOML files)
Data Flow
1. Abbey Road MPEG-TS → Decode → RGB frames
2. Downsample 2x → Pipeline Engine applies effects in order → Upsample 2x
3. Encode H.264 → HLS segments → Video Player
4. Slider change → REST PATCH → Pipeline updates params → next frame uses new values
