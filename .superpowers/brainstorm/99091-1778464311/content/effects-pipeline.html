Effects Pipeline: "Live Painting with Texture"

Replacing 6 image passes with 3 lean ones for a painterly canvas look

Current: 6-Pass Dalí Pipeline
  1. Sine-wave psychedelic distortion (coordinate remap)
  2. Bilateral filter (expensive edge-preserving blur)
  3. Color quantization (posterize to N levels)
  4. Morphological open/close (shape smoothing)
  5. Sobel edge detection (find boundaries)
  6. Oil painting region fill (second bilateral + blend)
~50-200ms/frame — bilateral filter alone is ~40% of total cost
Proposed: 3-Pass Painting Pipeline
  1. Mean-shift quantization (flat painted regions)
  2. Sobel edge overlay (visible brush boundaries)
  3. Canvas texture blend (static texture, one-time load)
~10-30ms/frame — no bilateral filter, no coordinate remap

What Each Pass Does

Pass 1: Mean-Shift Quantization → "Paint Regions"

Purpose: Collapse similar colors into flat regions — like paint strokes filling areas of canvas.

How: Downsample to half resolution → quantize each channel to N levels (8-12) → optional small box blur to smooth region edges → upsample back with nearest-neighbor (preserves hard edges).

Why not bilateral filter? Bilateral is O(n × kernel²) per pixel. Quantization is O(n) — just division and rounding. 10-50× cheaper for a similar "flat regions" look.

Tunable: Number of color levels controls how "abstract" vs "realistic" it looks. Fewer levels = more painterly.

Pass 2: Sobel Edge Overlay → "Brush Boundaries"

Purpose: Add visible dark outlines where color regions meet — like the edges of brush strokes or charcoal outlines on a painting.

How: Sobel gradient on the quantized grayscale → threshold → blend as dark lines over the color image. Same as current code, already fast.

Tunable: Edge thickness (blur kernel), darkness (blend factor), threshold (how many edges show).

Pass 3: Canvas Texture Blend → "Painted Surface Feel"

Purpose: Make it feel like paint on a physical surface. Adds subtle bumps, weave patterns, and imperfections.

How: Load a static canvas/paper texture image once at startup. For each frame, multiply-blend the texture over the processed image at ~10-20% opacity. The texture is tiled to match frame resolution.

Cost: Nearly free — it's just a per-pixel multiply+add on pre-loaded data. ~1-2ms per frame.

Tunable: Texture type (canvas, watercolor paper, linen), blend strength, texture scale.

Time-of-Day Color Behavior

Preserving the London-time color shift

The current system shifts the color palette based on London time (lighter at noon, darker at midnight). We keep this but apply it differently:

  • Keep color output (not grayscale) — the quantized colors already create a painted look
  • Warm/cool shift — instead of just grey level, shift the color temperature: warmer tones during golden hour, cooler blues at night
  • Edge color adapts — dark outlines during day, light outlines at night (same logic as current)

This is a creative choice you can decide on later — the pipeline supports either grayscale or color output.
